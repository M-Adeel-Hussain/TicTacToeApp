# 🎮 Tic Tac Toe Game (ASP.NET Core MVC)  

### 📝 Description  
This is a simple **Tic Tac Toe game** built using **ASP.NET Core MVC** with Razor Pages. Players can enter their names, play the game, and get a **"Congratulations" message** when someone wins. The game automatically resets after a win or draw.  

### 🚀 Features  
✅ Player name input for both players  
✅ Fully functional game logic  
✅ Win detection and "Congratulations" message  
✅ Auto-reset after win/draw  
✅ Simple and interactive UI  

### 🛠️ Technologies Used  
- **ASP.NET Core MVC**  
- **C#**  
- **Razor Pages**  
- **JavaScript (for game logic)**  
- **Bootstrap (for styling)**

### 📥 Installation & Setup  
1. Clone the repository:  
   ```sh
   git clone https://github.com/yourusername/TicTacToeApp.git
   ```
2. Open the project in **Visual Studio**.  
3. Build and run the project (`Ctrl + F5`).  
4. Play the game in your browser!  

### 🏆 How to Play  
1. Enter player names.  
2. Take turns clicking on the grid.  
3. The first player to get **three in a row (horizontal, vertical, or diagonal)** wins!  
4. If all boxes are filled and no one wins, the game ends in a **draw**.  
5. After a win/draw, the game **resets automatically**.
